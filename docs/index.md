# Welcome to ISYS！
## 前言
本站(ISYS)旨在整合一些信安(is)专业课的相关资源！

>有[图灵班学习指南](https://zju-turing.github.io/TuringCourses/)和[ZJU CS - All Sum in One!](https://isshikihugh.github.io/zju-cs-asio/)珠玉在前，笔者得以轻松地获取一些课程的信息，也因此受益匪浅。但是，受限于专业人数较少以及近些年课改带来的变化，is的课程资料相对比较分散，并且前辈们公开的资料并不是那么容易就能找到和找全的————那么，为什么is不能有一个自己的“学习指南”或是“asio”呢？因而我决定自建一个is专属的资源站。

欢迎任何贡献和斧正！

## 声明
本站尽力保证所提供的资源（或获取对应资源的途径）完善且实用，但本站不能保证所有资源都是绝对权威/完全正确的。
