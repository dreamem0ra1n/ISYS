# Welcome to ISYS！
## 前言
??? note "第一版"
    本站(ISYS)旨在整合一些信安(is)专业课的相关资源！

    >受益于[图灵班学习指南](https://zju-turing.github.io/TuringCourses/)、[ZJU CS - All Sum in One!](https://isshikihugh.github.io/zju-cs-asio/)和[求是潮 zju-icicles](https://github.com/QSCTech/zju-icicles)等优质项目，笔者得以轻松地获取一些课程的信息。但是，笔者发现受限于专业人数较少以及近些年课改带来的变化，is的课程资料相对比较分散，并且前辈们公开的资料并不是那么容易就能找到和找全的————那么，为什么is不能有一个自己的“学习指南”或是“asio”呢？因而我决定自建一个is专属的资源站。

    欢迎任何贡献和斧正！

??? note "第二版"

    >恭喜你，在浩如烟海的信息里找到了这段序言^^

    放在网络上的东西，迟早有一天会过期，但留下些记录未尝不是好事。ISYS存在不了多久，或许等到我大四了就会完完全全停止它的更新，然后ISYS又会被淹没在时代的浪潮下，悄无声息地被掩埋。

    其实之前一直期望有人愿意和我一起共建这个资源站的（我还挂在98的签名帖了，但好像0人在意。），现在想想还是算了吧，吃力不讨好的事情要不然就优化效率，要不然就最好不做:（

    如果你要问我做这个有什么意义，那我会告诉你没有什么意义，正反馈少得可怜却又累人。但，或许还是朴素的价值观驱使了我，去做这么一件有一点价值的事，哪怕它某种意义上只是自我感动罢了。

    话归正题，这里推荐阅读[谈谈如何让自己看上去、闻上去都像一个CS人](https://www.cc98.org/topic/5370849)，并且来更深地讲讲ISYS的理念和初衷。（叠甲：仅为个人观点，不喜勿喷）
    
    其一是培养自身的高信息素养。授人以鱼不如授人以渔，我认为[如何找到资源](杂项/工作流和信息渠道)比找到了什么样的资源更重要。它不仅要求你精通这个网络世界的搜索法则（just like a 贪婪的爬虫），还要求你能够独立思考，多方佐证————这份笔记是否准确、是否粗制滥造、是否适合自己...对于好坏，每个人都有自己的答案。另外，第一性原理也是信息素养的一部分：如果你想要如期毕业，就需要关注培养方案，并以此安排你的课表；如果你想要得到高分，就应该更多地关注应试（复习课、历年卷）；如果你更希望扎实地获得能力和知识，那么眼光就不止要看课程笔记了。

    其二是分布式管理-集中式汇总。其实在ISYS建立之前我就已经见过[力速双A - ZJUSAA](https://fsaa.pages.zjusct.io/fsaa/)、[Hikari of ME](https://hikari-of-me.pages.zjusct.io/hikari-of-me/)、[数学之韵](https://zju_math.pages.zjusct.io/mathweb/)、[ZJUCSSU](https://zju-cssu-dev.github.io/home/)等多个由学院/小组牵头的项目了，不得不说众人拾柴火焰高，凭我一己之力做不到同时维护课程信息和页面下挂载的资源————所以我转向了维护索引，将资源维护的责任交还给提供者本身，只做filter的工作。这样的好处就是，我们不用再担心站内文件和源文件diff然后出问题了（不过相对地，一旦链接挂了就什么也没了）。另外，“以课程为中心汇总”和“以笔记站为中心汇总”两者之间，我更倾向于前者，因为我们往往是因为已经心里有了要找某门课的预期而开始搜索的，比起先找笔记站再找具体页面，课程页面直接索引到对应资源的效率通常更高些。但这也并不是说“以笔记站为中心汇总”没有必要，维持信息来源的广泛性也是前面所说的信息素养的一环。

    其三是互通有无。这一点其实是老生常谈了，只不过因为相当重要所以再一次在这里提及。我不否认，在这座全国TOP3的学府里肯定有着那种目标明确并且左右逢源，不需要所谓资源站的任何帮助的同学，但总有一些时候、总有一部分人会需要搭把手的，毕竟我们无可避免地受限于“信息差”。从另一个角度自私地讲，我希望在我自己感到迷茫彷徨，不知所措的时候有人拉一把，有人为我指出一条明路。所以，**我希望通过ISYS帮到那些有需要的同学，哪怕他们因此而得的好成绩跟我没有任何关系**。或许，能改善一点在浙的就读体验也是好的吧。

    所以如果你觉得有帮助的话，不妨点点star或者来课程页面下评论两句跟课程有关的信息，这对于我来说是莫大的鼓励！

## 声明
本站的宗旨是建立一整套易用的、完善的课程相关信息索引，进而为课程压力较大的iser们节省从浩如烟海的帖子/站点里筛选有用信息的时间。

本站无法保证链接的永久有效性和索引内容的真实/权威性，索引链接或文字表述有任何问题请联系`cc98@晚自习的梦`修改。
