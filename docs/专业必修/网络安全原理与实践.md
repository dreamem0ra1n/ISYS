# 网络安全原理与实践

## 课程信息
!!! note "培养方案推荐修读学期：**大三春**"

### 课程简介
摘自教务网：

> 本课程是一门面向信息安全专业高年级本科生开设的专业必修课以及计算机科学与技术与软件工程等专业高年级学生开设的专业选修课。课程既是一门理论性课，更是一门实践性极强的课程。教学目标在于使学生较全面地学习有关网络安全的基础理论和实用技术，掌握网络系统安全防护的基本方法，培养网络安全防护意识，增强网络系统安全保障能力。教学任务是使学生打下良好的网络安全理论基础，掌握网络安全的基本原理、主要技术以及解决方案，培养对网络安全的分析与设计的能力。
