# 数据安全与密码学基础

## 课程信息
- 推荐修读学期：**大二秋冬**

### 课程简介
> 摘自教务网的课程信息

本课程将介绍服务于数据安全的密码学基础，这些密码学基础和技术对深入研究和探索数据安全是非常重要的。通过本课程的学习，学生将学习现代密码学的基本概念和多项技术。具体而言，学生将首先学习密码学从古典密码到现代密码的发展，进而学习现代密码学的安全基石---可证明安全。在可证明安全的框架下，学生将学习包括对称加密，公钥加密，哈希函数，数字签名，以及零知识证明等多项密码学技术，以及区块链安全技术和数字货币的基本原理。
