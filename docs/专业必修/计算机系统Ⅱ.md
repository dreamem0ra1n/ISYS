# 计算机系统Ⅱ

## 课程信息
!!! note "培养方案推荐修读学期：**大二秋冬**"

### 课程简介
计算机系统（简称sys）是在信安课改中诞生的三门课，内容包含了传统的四件套（数字逻辑设计、计算机组成、计算机体系结构、操作系统）。sys2是计算机系统贯通课程的第二门课。

### 任课教师
卢立/申文博、常瑞/吴磊

### 成绩构成
=== "25秋冬，常瑞/吴磊班"
    - Homework Assignment 10%
        - TBD
    - Labs 60%
        - lab0 - CPU Design Review (4%)
        - Lab1 - Pipeline CPU Design (10%)
        - Lab2 - Stall,Forwarding and Bus (10%)
        - Lab3 - Convolution Accelerator (4%)
        - Lab4 - Kernel Boot (4%)
        - Lab5 - Interrupt (6%)
        - Lab6 - Simple Scheduling (8%)
        - Project - Running Naive OS on CPU (14%)
        - Bonus(original，后被替换为下面一个) - 实现 `snprintf` 函数
        - Bonus(new) - ARM 架构下 Linux 内核的编译与 QEMU 仿真 (4%)
    - Final Exam 30%
