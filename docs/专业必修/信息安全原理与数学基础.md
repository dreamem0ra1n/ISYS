# 信息安全原理与数学基础

## 课程信息
- 推荐修读学期：**大一春夏**

### 课程简介
说是信息安全原理，但其实主要是数学课————是一门离散数学加概率论的“拼好课”（也就是为什么信安不修概统和离散）

### 任课教师
秦湛（概率论部分）/张秉晟（离散数学部分）

### 成绩构成(25春夏)
- 作业（50%）：学在浙大，每周四布置作业（共7个，每个7-8分）

- 期末（40%）

- 出勤（10%）：助教记录
