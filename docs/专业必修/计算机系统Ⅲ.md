# 计算机系统Ⅲ

## 课程信息
- 推荐修读学期：**大二春夏**

### 课程简介
计算机系统（简称sys）是在信安课改中诞生的三门课，内容包含了传统的四件套（数字逻辑设计、计算机组成、计算机体系结构、操作系统）。sys3是计算机系统贯通课程的最后一门课。

### 任课教师
常瑞/吴磊/申文博

摘自教务网：

> 平时作业（Homework）：5%
>
> 课堂宣讲（Presentation）：5%
>
> 课程实验（Projects）：60% 
>
> 期末笔试（闭卷）： 30%
