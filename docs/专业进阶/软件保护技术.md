# 软件保护技术

## 课程信息
!!! note "培养方案推荐修读学期：**大二秋冬**"

### 课程简介
摘自教务网：

> 本课程旨在教授学生如何理解、修改、加密可执行文件中包含的机器代码。学习软件保护技术的目标主要包括以下四个方面：1、探索可执行文件的结构2、学习修改程序的技巧3、掌握软件加密的方法4、提高调试程序的能力学习本课程将非常有助于培养学生较强的计算机系统设计和开发能力。
