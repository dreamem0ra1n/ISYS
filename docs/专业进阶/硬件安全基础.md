# 硬件安全基础
<div class="course-tags"><span class="tag tag-advanced">专业进阶</span><span class="tag tag-credit">2.5学分</span><span class="tag tag-location-yq">玉泉</span><span class="tag tag-number">CS3209M</span></div>
!!! note "培养方案推荐修读学期：**大二春夏**"

### 课程简介
摘自教务网：

> 当前，包括嵌入式设备和通用处理器在内的各级系统都需要通过硬件支持的安全机制来提高整体的安全性能。而硬件本身的实现机理、泄露原理、攻击手段和防御措施等，都与传统的软件层面的攻防有着很大的不同。本课程是硬件安全的入门课程，拟主要介绍旁路攻击、故障攻击、相关防御、物理不可克隆函数、硬件木马、微架构攻击的基本概念。
