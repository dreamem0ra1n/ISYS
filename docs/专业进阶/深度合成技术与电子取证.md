# 深度合成技术与电子取证

## 课程信息
!!! note "培养方案推荐修读学期：**大三春夏**"

!!! note "该课程在智云课堂名为“电子取证”，98没有任何相关帖"
### 课程简介
摘自教务网：

> 本课程将介绍深度合成及电子取证的基本概念、原理、技术、工具以及实用技能，这些基本概念是对计算机或其他数字设备进行数字调查所必需的。学生将学习到数字犯罪现场调查过程中可能用到的重要方法。从最初的数据采集、到数据分析、再到数据溯源与鉴伪，学生将学习如何创建事件响应计划并实施数字设备取证事件响应策略。此外，通过实际的实验练习，学生还将学习到如何对实际事件进行调查，体验包括获取、检查、分析、证据保存在内的完整取证流程。本课程还将涵盖多媒体取证、移动设备取证以及取证对抗等数字调查分析领域的先进技术。
