# 人工智能安全
<div class="course-tags"><span class="tag tag-advanced">专业进阶</span><span class="tag tag-credit">2.5学分</span><span class="tag tag-location-yq">玉泉</span><span class="tag tag-number">CS3160M</span></div>
!!! note "培养方案推荐修读学期：**大三春夏**"

### 课程简介
摘自教务网：

> 人工智能技术已广泛应用于工业、医疗、交通、安防等行业，推动了产业的智能化变革。然而，人工智能技术的内在脆弱性以及缺乏可解释性，导致人工智能系统面临着严峻的安全威胁。本课程主要讲授人工智能安全的基本概念和研究进展，以人工智能系统面临的安全事件为起点，介绍人工智能安全涵盖的主流研究方向，从鲁棒性、完整性、隐私性、公平性、可解释性等多个角度展开，详细介绍人工智能技术面临的安全威胁和防御手段。课程设置实验教学，邀请蚂蚁金服的安全专家共同讲授，通过AI安全攻防演练，提高学生的代码能力和实践能力，深化学生对理论知识的理解，为今后从事人工智能安全相关工作和科学研究提供打下坚实的基础。
