# 网络空间安全导论
<div class="course-tags"><span class="tag tag-elective-basic">专业选修-应用基础</span><span class="tag tag-credit">1.5学分</span><span class="tag tag-location-zjg">紫金港</span></div>
!!! note "培养方案推荐修读学期：**大一春夏**"

### 课程简介
摘自教务网：

> 随着计算机技术的飞速发展，网络空间安全问题越来越受关注。本课程介绍若干作为网络空间安全理论与技术的重要基础或工具，对于网络空间安全专业的学生，有必要较为系统和深入的补充相关知识，以便为进一步学习网络空间安全理论及技术奠定良好的基础。

### 任课教师
任奎/张秉晟/罗梦/张明雪

### 成绩构成
=== "26春夏"
    摘自教务网：

    > 出勤、课堂发言讨论30%
    >
    > 期末考试(或project)：70%。

=== "25春夏"
    - 课堂参与 10%
    - 期末报告 90%
        - 课程报告：比如嵌入式设备安全，可以自己查阅一个嵌入式设备的详细软硬件配置，然后调研相关资料，阐述相应安全威胁或安全机制的基本原理，根据课程内容完成3000-5000字的报告。
        - 例子：根据技术文档完成漏洞复现/ARM TrustZone/Intel SGX安全机制实现（罗）；区块链技术/隐私计算技术/加密数据库技术（张）
        - 主题：
            - Network Security: 
                - Intrusion Detection
                - Honeypot or Sandbox
                - Web Vulnerability analysis
                - Webshell detection
            - IoT Security: 
                - Side Channel attack, Sensor Security
                - Deepfake via signals
            - System Security: 
                - Operating system security
                - Software attack & defense
                - Firmware security
            - Cryptography & Data Security:
                - historical cipher
                - introduction to modern cryptography
                - secure multi-party computation
                - privacy preserving machine learning
