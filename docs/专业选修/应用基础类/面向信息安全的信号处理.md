# 面向信息安全的信号处理
<div class="course-tags"><span class="tag tag-elective-basic">专业选修-应用基础</span><span class="tag tag-credit">2学分</span><span class="tag tag-location-yq">玉泉</span></div>
!!! note "培养方案推荐修读学期：**大三秋冬**"

### 课程简介
摘自教务网：

> 本课程涉及八方面的内容：一、信号与系统基础：阶跃信号与冲激信号，线性时不变系统，卷积。二、傅里叶变换与傅里叶级数：周期信号的傅里叶级数分析，傅里叶变换原理和基本性质，采样定理。三、信号的向量空间分析：信号向量空间的基本概念，信号的正交函数分解，相关，能量谱和功率谱。四、随机变量：随机变量的分布函数，概率密度和数字特征，朴素贝叶斯法。五、随机过程：平稳随机过程，随机过程的联合分布和互相关函数，随机过程的功率谱密度。六、马尔可夫过程与马尔可夫模型：马尔可夫链的转移概率及矩阵，马尔可夫过程，隐马尔可夫模型。七、降维与度量学习：线性降维，非线性降维，距离度量。八、信号处理在信息安全中的应用：物联网安全，认知无线电安全，智能电网安全等。
