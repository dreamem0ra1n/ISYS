# 社交网络安全与隐私

## 课程信息
!!! note "培养方案推荐修读学期：**大三夏**"

!!! note "认定类别：**国际化课程**"

### 课程简介
摘自教务网：

> 随着互联网使用量的增加，在线社交网络 (OSN) 的使用呈指数级增长。OSN帮助用户在全球范围内建立社交和专业网络。OSN重要特征是信息和意见的共享。用户可以描述最近的状态、活动，分享照片、视频、应用等。微信、TikTok、新浪微博、Facebook、YouTube、Twitter、Instagram、LinkedIn等OSN已经成为互联网用户日常交流的首选方式。用户每天花费大量时间在社交网络中更新他们的信息、与其他用户交流以及浏览彼此的页面。 OSN的流行使它们成为了攻击者侵犯用户隐私、传播虚假信息、发起各种网络攻击的重要目标平台。然而，人们对社交媒体网络的隐私和安全问题仍然缺乏了解。本课程将帮助学生从多个方面了解社交媒体网络中的安全和隐私问题以及常见的应对方法，并掌握研究社交媒体网络所需具备的数据采集、处理及分析技术。具体来说，本课程将介绍社交媒体网络的基础知识，介绍OSN数据收集和分析常用的技术和工具，讨论 OSN 中的信任机制、隐私政策、安全挑战、假新闻、各种形式的网络犯罪等课题，最后将介绍应对OSN安全和隐私问题的防御措施和常见方法。
