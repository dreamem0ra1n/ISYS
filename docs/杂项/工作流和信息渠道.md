# 工作流和信息渠道
!!! note "这个页面将会揭示ISYS的工作流，同时补充一些可供参考的信息获取渠道。"
## 工作流

1. 根据教务网上的培养方案创建课程页面（注意：教务网有时候会更新培养方案）
2. 课程页面对应部分的信息来源：
    - 课程英文名称（教务网-课程信息查看）
    - 课程简介/课程学分/课程号（教务网-课程信息查看）
    - 任课教师/上课地点（教务网-开课情况）
    - 教材信息（教务网-课程信息查看、智云课堂）
    - 成绩构成（教务网、智云课堂、查老师）
    - 相关资源（见下文“渠道”）
3. 定期更新同步相关信息。（寒暑假大更新，平常小更新，如果留存信息过于陈旧会考虑进行归档）

## 渠道

### 教务网
在教务网有一个“开课情况”功能，可以查看各个学期的课程安排（包括时间/地点/考试时间/专业所属教学班等信息，最远支持查看下一学期）

与之配套的，教务网还有一个“课程信息查看”功能，可以查看课程的基本信息/简介/中英教学大纲/教材。从大纲里可以看到该门课程的课程安排和成绩构成（不过最终的成绩构成还是取决于上课时老师说什么以及PPT上写什么）

> ISYS上的成绩构成、教材信息、课程简介默认都从教务网搬运（除非已经从智云课堂找到了对应信息）

### 智云课堂

智云课堂的作用是观看回放。智云课堂的回放会有该门课程的成绩构成等信息（一般前两节课都会讲），但2026年3月起，智云课堂进行了升级，“课堂视频直播和回放权限将由任课老师设定，默认面向本教学班开放，且回放有效期为2年”，不过大多数课程的老师会设置默认通过，申请了还是能正常回看的。

### 查老师

在查老师[https://chalaoshi.de/](https://chalaoshi.de/)上，我们可以查找对应老师的评价和菌剂（仅供参考）

### 教师个人主页门户网
访问[person.zju.edu.cn](https://person.zju.edu.cn)可以查看教师的个人信息（不过没有什么有用的信息）。

### cc98

98搜索是一个很好的寻找资源的方法。比如课程《计算机系统Ⅰ》，我们可以搜索课程名称“计算机系统”（注意，有的人可能会在后面加“Ⅰ”或是“1”甚至是“一”，我们需要排除这些因素确保能够搜到足够多的有效帖子），或者搜索其缩写“sys”，或是“计统”（这个简称比较少见）

### 朵朵校友圈

这个能搜索到的信息十分有限，和98搜索方法类似，不过它支持模糊搜索。
