# 信息安全课程综合实践(CTF101)
<div class="course-tags"><span class="tag tag-practice">实践教学</span><span class="tag tag-credit">2.5学分</span><span class="tag tag-location-zjg">紫金港</span><span class="tag tag-number">IS2004</span></div>
!!! note "培养方案推荐修读学期：**大一短**"

### 课程简介
CTF101是信安从24级起加入培养方案的一门短学期课程，AAA的前辈们会在为期两周的课程内为同学们讲解CTF五大方向————crypto、misc、pwn、reverse、web的基础知识。

**课程安排**：第一周由导论课+5个方向的基础课组成，第二周将是5个方向的专题课+专家分享/课程总结。

### 任课教师
常瑞/申文博

### 成绩构成(25短学期)
- 考勤（5%）
    - 允许线上上课，但需要提前说明，不影响成绩
    - 没有提前说明 / 请假，缺勤会扣一定分数
- 基础周（55%）
    - Lab 0 全部完成（5%）
    - 五个方向每个方向 Lab 1，每个占 10%
- 专题周（40%）
    - 五个方向选两个方向学习专题，每个方向两个 Lab，每个占 10%
    - 少量 bonus：考勤 / 基础周 / 专题周 三个部分独立，不互相溢出
- 鼓励选择多个专题，但最终选择分数较高的两个专题计分
